## QuickNAS

A quick, low cost and simple NAS solution proof of concept made in the course of a 24h hackathon.

This was achieved thru making a simple custom Alpine Linux live ISO that runs [Copyparty](https://copyparty.eu/) by extending [Alpine's aports scripts](https://gitlab.alpinelinux.org/alpine/aports). This repo holds said extensions + automation scripts for building the live ISO in an alpine virtual machine.
